## 一句话理解 nasdeck

把原本要 SSH 敲命令才能看到的硬件状态——CPU、内存、温度、风扇、硬盘 SMART、阵列卡、存储卷、Docker、端口占用——装进一块 UNRAID 风格的网页面板，以标准 FPK 应用装进飞牛桌面，打开即用。

## 开发铁律速查（改代码前必读）

1. **权限**：设置/写操作仅管理员——后端 `TrimAuthDep` 强制校验，前端按 `identity.canWrite` 控制渲染，两端都要守。
2. **假数据清零**：正常形态必须真实采集；无数据源的字段显式 `—`，不许猜；mock 仅允许在整页后端不可达时作演示回退，且必须与 live 数据同形状。
3. **版本单源**：版本号唯一来源 `backend/pyproject.toml`；`fpk/manifest` 由打包脚本注入 `@VERSION@`，不得手写。
4. **零裸 SQL**：业务/DDL 一律经 ORM 与 SQLAlchemy 检查器表达；连接 PRAGMA 是唯一豁免，只允许存在于 `db/session.py`。
5. **采集宁丢不堵**：周期采集流经单写者 ingest 通道攒批落库，任何新采集点不得在 tick 内同步写库。
6. **真机改动需实测**：涉及 fnOS 集成（cgi 反代、生命周期脚本、硬件工具）的改动，合并前在真机过一遍安装/升级/卸载。
