# 01 项目概览

## 项目定位

nasdeck 是飞牛 OS（fnOS）的第三方硬件监控面板，以标准 FPK 应用发布到飞牛应用中心。设计目标：

- **打开即用**：桌面图标 → 飞牛登录态 → 面板，不需要 SSH、不需要终端命令
- **低占用采集**：跑在 NAS 低功耗硬件上，1 秒级采集零外部进程 fork（内核文件直读）
- **分级安全**：面板绑定回环地址，经飞牛 cgi 反代获得登录态；读操作校验登录身份，风扇调速等写操作仅管理员

## 功能全景（13 个视图）

| 视图 | 路由 | 内容 |
|---|---|---|
| 总览 | `/nasdeck/dash` | CPU/内存/网络/磁盘 IO/GPU/功耗/风扇/Docker 单页仪表盘，WS 秒级刷新 |
| 硬件检测 | `/nasdeck/detect` | 系统/主板 DMI/CPU/内存 SPD/网卡/阵列卡形态识别 + 运行环境自检 |
| 硬盘 | `/nasdeck/disks` | SMART 健康/温度/通电时长，在线自检（短/长/搬运），管理员发起 |
| 存储卷 | `/nasdeck/storage` | 阵列设备、真实层级存储拓扑树（控制器→阵列→成员盘→分区/挂载点）、卷用量 |
| 系统 | `/nasdeck/system` | 系统资源图表、进程管理（白名单保护）、环境变量、Docker 容器 |
| 温度 | `/nasdeck/temps` | 传感器温度墙（CPU/主板/NVMe/机械盘/芯片组） |
| 趋势 | `/nasdeck/sys-hist` | 六维度历史曲线（24h/7d/30d）、区间统计、报告导出 |
| Docker | `/nasdeck/docker` | 容器状态与端口映射 |
| 端口 | `/nasdeck/ports` | 监听端口/进程/可达性，管理员可释放（终止进程） |
| 风扇 | `/nasdeck/fan` | PWM 接管调速、温度→占空比曲线编辑、安全接管（FCS） |
| 自动化 | `/nasdeck/automation` | 告警规则/通知渠道（Bark/Telegram/邮件/Webhook）/事件历史 |
| 手册 | `/nasdeck/manual` | 面板内置操作手册 |
| 关于 | `/nasdeck/about` | 版本、构建信息 |

## 技术栈

| 层 | 技术 |
|---|---|
| 后端 | Python 3.12 · FastAPI · uvicorn · SQLAlchemy 2 (async) + aiosqlite · APScheduler · psutil |
| 前端 | Vue 3 (script setup) · Vite · Pinia · Vue Router · Element Plus（按需）· 自绘 SVG 图表（零图表库） |
| 数据库 | SQLite（WAL 模式，单文件，落 `TRIM_PKGVAR`） |
| 打包 | fnpack FPK · 随包离线分发 Linux cp312 site-packages · 解释器来自应用中心 `python312` 运行时 |
| 外部工具（按能力降级） | smartctl · sensors · mdadm · dmidecode · i2c-tools · ethtool · intel_gpu_top · storcli（随包内置）· lsblk · lspci |

外部工具全部经**能力决策层**（`services/hardware/policy.py`）在启动时判定在位与否，缺失时对应功能显式降级（显式 `—`），运行期不切换策略、不反复探测。

## 仓库结构

```
nasdeck/
├── backend/            # FastAPI 后端（app/ 业务 + tests/ 139 用例 + pyproject.toml 版本单源）
│   └── app/
│       ├── api/        # v1 路由（monitor/storage/system/control/alert/report/hardware）+ WS
│       ├── core/       # 配置/鉴权依赖/异常信封/日志/静态托管
│       ├── db/         # session（PRAGMA 调优）/ init_db（结构自愈）/ ingest（单写者）
│       ├── models/     # ORM 模型（metrics/alert/control/hardware/storage/system）
│       ├── schemas/    # Pydantic DTO（契约 §2 一一对应）
│       ├── services/   # monitor 采集 / control 风扇 / alert 引擎 / storage 存储 / report 报告
│       ├── tasks/      # 1s/5s/60s 采集器 + 降采样 + 调度器
│       └── utils/      # async_cmd（外部命令封装）/ sysfs / 单位换算
├── frontend/           # Vue 3 SPA（modules/nas 为全部业务视图）
├── fpk/                # FPK 包定义（manifest/cmd 生命周期/wizard/app 入口 shim）
├── scripts/            # build_fpk.py 一键打包 + draw_icons.py
├── docs/               # 契约、使用手册、截图、本 wiki
└── prototype/          # 早期 HTML 原型（设计参考，不参与构建）
```
