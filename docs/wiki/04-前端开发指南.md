# 04 前端开发指南

## 技术栈与目录

Vue 3（script setup）· Vite · Pinia · Vue Router · Element Plus（unplugin 按需）· **自绘 SVG 图表（零图表库依赖）**。

```
frontend/src/
├── modules/nas/          # 全部业务
│   ├── views/            # 13 个视图（UNRAID 风格页）
│   ├── components/       # U* 组件 + 图表/图标组件
│   ├── api/              # client.js（请求层）/ data.js（数据适配层）/ ws.js（WS 组合器）
│   ├── composables/      # useViewData（视图数据装载）
│   ├── stores/           # identity（身份）/ realtime（WS 单连接）
│   ├── mock.js           # 演示回退数据（必须与 live 同形状）
│   └── routes.js         # /nasdeck/* 路由（懒加载 + keepAlive）
├── layouts/              # UnraidLayout（主布局）/ index.vue（旧管理布局）
├── components/           # 全局通用组件（unplugin 扫描目录）
└── styles/unraid.scss    # UNRAID 风格基座（令牌 + 组件类，全部嵌套在 .nd 根容器下）
```

## 构建模式

```bash
cd frontend
pnpm install --frozen-lockfile        # pnpm 12.x
pnpm dev                              # 开发模式，代理到本地后端（VITE_PROXY_TARGET）
pnpm build                            # 站点模式（base=/）
pnpm build -- --mode fpk              # FPK 模式（base= cgi 反代前缀）——打包脚本自动调用
pnpm lint / pnpm lint:style           # eslint / stylelint
```

`--mode fpk` 的差异在 base 路径：FPK 形态页面经 `/cgi/ThirdParty/com.dashboard.nasdeck/index.cgi/` 反代打开。**手改 dist 后复用 `--skip-frontend` 打包时，dist 必须是 fpk 模式产物。**

## 数据适配层（data.js）——本前端的核心约定

视图不直接消费接口原始返回，一律经 `data.js` 适配为**与 mock 同形状**的数据：

- `useViewData(loader, mockInitial)` 装载；后端不可达 → 整页回退 mock（`live:false`）；**个别源缺失保持骨架空值，不许回退假数据**
- **假数据清零铁律**：正常形态必须真实采集；无数据源的字段显式 `—`（如盘位无真实槽位数据显示 `—` 不显示序号）；mock 仅作演示回退且形状与 live 一致（改字段时双向核对 `mock.js`）
- 多源并发用 `Promise.allSettled`（`fetchDashboard` 8 路、`fetchSystemCharts` 5 路并行）；同 URL 高频请求走请求级缓存（`firingEvents` 30s）

## 实时数据（ws.js + stores/realtime.js）

- 全站**单 WS 连接**（Pinia store 引用计数），视图不直连 socket
- WS 断开 → 指数退避重连（1s 起上限 30s）→ 连续失败切 2s 轮询降级 → 恢复自动切回
- **CGI 反代形态**（路径含 `index.cgi`）网关不透传 WS：直接轮询，省掉必败重连空窗
- 视图消费：watch store 快照更新本地历史缓冲（**缓冲全部封顶**：Dash 40/60 点、Temps 40、SysHist ≤360，无内存无限增长）

## 组件体系

### U* 组件（modules/nas/components，须显式 import）

`UPageHeader`（标题+tag+最后更新）、`UPop`（确认气泡）、`UDrawer`/`UModal`、`UDropdown`、`USpark`（磁贴迷你线）、`ULineChart`（主折线图：series/labels/zoom/tipFmt）、`UCurveEditor`（风扇曲线拖拽编辑）、`FanRotor`（rAF 风扇转子，尊重 `prefers-reduced-motion`）、`IconSprite`+`UIcon`（SVG symbol 图标，`<u-icon name="...">`）。

**unplugin 导入坑**：`Components({ dirs: ['src/components'] })` **不扫** `src/modules/nas/components`——nas 组件在模板里用必须**显式 import**，否则渲染成 0×0 空元素（不报错、布局不塌，极难察觉）。

### 图表：自绘 SVG（utils/chart.js）

`renderLine`/`renderSpark` 直接以字符串构建 SVG（niceScale 刻度、十字线 tooltip、dataZoom），`ULineChart`/`USpark` 封装 + ResizeObserver 重绘。**不引入 ECharts/Chart.js**——NAS 面板场景体积与渲染成本优先。改图表逻辑去 `chart.js`，别往视图里塞 SVG 操作。

### 样式（unraid.scss）

- 全部规则嵌套在 `.nd` 根容器下（黑/白双主题令牌，`data-theme` 切换）；新组件样式写进对应嵌套块，**别在组件里裸写全局选择器**
- **类名地层**：`.nd` 同时是根容器类与树节点标签的历史类名（后者已改名 `.tn`）——`.nd` 上有 `min-height:100vh`，任何节点级元素复用 `.nd` 类名都会在 flex 子项块化后撑到一屏高；新增类名先 grep `.nd` 确认不撞
- 菜单样式切换（完整 ↔ 纯图标）类挂在**根容器**：`<div class="nd" :class="{'nav-icons': iconsMode}">`——SCSS 选择器是 `&.nav-icons`（编译为 `.nd.nav-icons`），绑定错元素或错类名都会静默失效

## 视图开发清单

1. `routes.js` 注册（懒加载 + `keepAlive: true`）
2. `data.js` 写 `fetchXxx`（Promise.allSettled 多源 + 适配为 mock 同形状）与 `emptyXxx` 骨架
3. `mock.js` 补同形状演示数据（版本号字段用演示值，不追真实版本）
4. 视图模板：`useViewData` 装载；`identity.canWrite` 控制写操作渲染；定时器/WS 订阅随 `onActivated/onDeactivated` 启停
5. 权限与假数据两条铁律自查（见 [Home](Home.md)）
