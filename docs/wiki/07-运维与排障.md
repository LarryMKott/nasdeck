# 07 运维与排障

## 日志

- 位置：FPK 形态 `${TRIM_PKGVAR}/app.log`（`cmd/main` 重定向）；开发形态 stdout
- 级别：dev 前缀包默认 **DEBUG**（真机排查采集链路），正式包 INFO；配置向导可显式覆盖（落 `runtime.env`）
- **外部工具调用主线索**：DEBUG 下 `async_cmd._log_call` 记录每次 smartctl/storcli/sensors 调用的完整命令行、退出码、输出量与耗时——「系统信息获取情况」排障先看这里
- `/system/env`（硬件检测页的运行环境自检）呈现各工具/驱动的安装期自举结果，缺失项带安装提示

## 常见问题 → 定位路径

| 现象 | 先查 | 机理 |
|---|---|---|
| 采集秒级跳秒 | `app.log` 中 medium_tick/fast_tick 异常；DB journal 模式 | 历史问题：默认 journal 下 1s 采集每 commit 全量 fsync 撞 5s 写事务。已修：WAL + NORMAL + 通知移出事务 + 温度回填改内嵌。再现则查是否有新的 tick 内同步写库 |
| 盘温/健康缺失（显式 —） | `/system/env` 里 smartctl 是否在位；DEBUG 日志 smartctl 调用 | 无外网安装跳过工具 → 功能降级；盘休眠（standby）该轮无读数属正常；NVMe 按控制器探测，`nvme0n1` 回退匹配 |
| 阵列卡不识别 | `/system/env` storcli 项；storcli 手动执行 | MegaRAID 走随包 storcli64（15s TTL 缓存）；HBA 直通走 lspci 检测；纯 SATA 无卡显示直连。`NASDECK_STORCLI_PATH` 可指定路径 |
| 历史曲线只有最近 2 小时 | raw 保留期配置 | raw 默认保留 120 分钟，更长窗口走 1m/10m 聚合表——聚合由降采样任务滞后生成，新装实例头几小时属正常 |
| Docker 列表不可用 | docker CLI/socket 是否存在 | `docker ps` 15s 超时 + 子进程回收；daemon 卡顿不拖垮其它接口 |
| WS 不推送（总览不动） | 浏览器地址是否 cgi 形态 | cgi 反代不透传 WS 升级，属已知——前端自动降级 2s 轮询；若轮询也不动查后端存活 |
| 风扇失控担忧 | FCS 状态（风扇页） | 安全接管：接管失败/超时自动回退 BIOS 控制；关停时 `restore_all_zones` 恢复 |
| 端口占用安装失败 | 换向导端口或停占用服务 | 安装期预检回环端口；面板不对外暴露，冲突只可能来自本机服务 |

## 数据与配置位置（真机）

| 内容 | 路径 |
|---|---|
| SQLite 历史库 | `${TRIM_PKGVAR}`（@appdata，升级/重装保留） |

## 真机验收清单（每版发布前）

1. 安装 → 桌面图标出现 → 打开走 cgi 反代（登录态生效；未登录被拦）
2. 总览秒级刷新（WS 或轮询降级均活）、温度/SMART/风扇/Docker 有真实数据，缺失项显式 `—` 而非报错
3. **分级鉴权**：普通用户可看，风扇调速/进程释放/自检发起等写入口不可用；管理员全通
4. 风扇接管：接管 → 曲线生效 → 释放 → 回 BIOS 控制；中途杀进程重启后状态对账正确
5. 告警链路：造一条超阈值规则 → firing 事件 → 通知渠道到达 → 恢复自动 resolve
6. 历史趋势：跑 1 天以上后 24h/7d 窗口有聚合数据；报告导出（CSV/MD/HTML）可下载
7. 升级安装旧版 → 新版：数据保留、DB 结构自愈、版本号/更新弹窗正确
8. 卸载重装：@appdata 保留与清除两种路径行为符合预期
9. i3 核显机型：GPU 利用率/温度有数（intel_gpu_top 长驻进程）；无核显机型 GPU 区显式降级

## 已知限制

- WS 经 cgi 反代不透传——前端已按轮询降级处理；若未来飞牛网关支持 WS 透传可切回
- fnOS 统一网关（Unix Socket）形态被放弃：飞牛会周期性清空第三方 gateway 入口（真机实测）
- DB 无 Alembic：结构演进靠启动自愈 + 整库重建（白名单内），正式发布前必须替换迁移方案
- storcli 解析面向 Broadcom/LSI 常见输出；冷门卡型如解析失败按无阵列卡降级，欢迎带 `storcli /c0 show` 原始输出提 issue
