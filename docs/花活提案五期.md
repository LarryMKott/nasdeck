## Y. 效果引擎与分级总闸（本期地基）⭐ 花哨 1 / 实用 5 / 工作量 S

**效果**：设置页新增「视觉效果等级」：**关闭 / 标准 / 拉满 / 自动**（默认自动）。所有花活效果（本期 Z–AF 与既有弹幕/HUD/礼花）统一注册到效果引擎，按档位启停：
- **关闭**：全部花活熄火，纯数据仪表（老平板救急/极客强迫症）。
- **标准**：默认档——弹幕、分享卡、Kiosk 转场等轻效果在，重效果（流体/声音/RGB 边框）不启用。
- **拉满**：全部效果开，含 WebGL 流体、氛围灯、声音化。
- **自动**：进场采样 2 秒帧率（<30fps 自动降标准，持续 <15fps 降关闭），结果记 localStorage 不再折腾——四期 U 的探测模块同一套。

**实现要点**：`useEffects()` 组合式单例 + `effectTier` store；组件侧 `v-if="fx('fluid')"` 一行声明注册；个人档存 localStorage，Kiosk 用机器级档位（system_settings，管理员可写）。
**改动面**：store + 组合式 + 既有花活（H/P/B）逐个接入声明。

## Z. 机箱热成像模式（热像仪视角）⭐ 花哨 5 / 实用 3 / 工作量 S

**效果**：温度页/立体机箱新增「热成像」滤镜：铁红调色板（ironbow：黑→紫→橙→亮黄，军规热像仪同款）重映射所有温度面色，叠加细扫描线、轻微暗角与画面噪点，部件读数变成热像仪十字准星 + 边角 `℃` 大字 HUD。一秒从监控面板变进《铁血战士》视角。

**实现要点**：
- 纯色板数学零依赖：现有 60/75/85 分级色 → ironbow 查表函数 ~30 行；F 的 2D 热力图与三期 R 机箱渲染器都只是换一个 colormap 注入，渲染管线不动。
- 扫描线/噪点/暗角全 CSS（repeating-linear-gradient + 动画一层），拉满档才开噪点动画，标准档只有色板。
- 真实边界：色板只吃真实温度值；无温度的部件在热像仪里就是背景黑——「看不见的才是冷的」恰好是热像仪的正确语义。

**改动面**：colormap 模块 + F/R 渲染入口注入参数 + 视图切换钮；零后端、零依赖。

## AA. 风道流体模拟（真实流体力学气流）⭐ 花哨 5 / 实用 2 / 工作量 M（前置：三期 R2）

**引入件**：[WebGL-Fluid-Simulation](https://github.com/PavelDoGreat/WebGL-Fluid-Simulation)（MIT，浏览器流体模拟名作，移动端可跑，单文件架构好裁剪）。

**效果**：机箱内气流从「粒子沿样条飞」升级为**真实流体**：风扇 RPM 驱动 splat 速度与密度，进风口持续注入冷色墨流、出风口抽走，CPU/盘热区按实时温度持续「蒸腾」热色墨——风道绕流、涡旋、热羽流全是物理算出来的，不是画出来的。

**实现要点**：
- fluid 内核裁到 ~800 行放 `vendor/fluid.js`：分辨率降到 128 以下网格 + 半速率求解，GPU 占用可控；仅「拉满」档 + WebGL 探测通过才挂载，其余档位回退 R2 粒子层（粒子层保留不删，就是它的兜底）。
- 数据绑定：R2 已有 RPM/温度 → 粒子驱动层，本项只是把驱动器从粒子发射器换成 fluid splat 调用，**数据绑定层完全复用**。
- rAF 单实例 + 页面隐藏即停（同示波器护栏）；iframe/上下文丢失 catch 后自动降粒子层。

**改动面**：依赖 1 件（vendor 适配）+ `isochassis/fluid-layer` + R2 驱动层解耦。前置：三期 R 至少交付 R2。

## AB. NAS 声音化（听见你的机器）⭐ 花哨 5 / 实用 2 / 工作量 M

**引入件**：零依赖（原生 Web Audio API 程序化合成）；Tone.js（MIT）仅作备选不默认引入。

**效果**：右下角一个「声音」开关（默认关，用户手动开启——浏览器自动播放策略本就要求手势启动）：
- **风扇** = 白噪 + 低通滤波，截止频率/音量随真实 RPM 连续变化——转速听得出；
- **硬盘活动** = 稀疏雨滴颗粒声，IOPS 越高雨越密（按盘聚合，不分盘出声）；
- **CPU** = 极低频 hum，负载抬升基波；
- **告警** = warning 一声短音、critical 双音上扬（不是恐怖片音效，克制）。
- Kiosk 模式配合即「机房白噪音发生器」，助眠新场景（认真）。

**实现要点**：全程序化合成无音频素材（包体零增）；每路一个 GainNode 母线，静音档一键全灭；指标更新 1s 档取自 realtime store，参数变化用 200ms 斜坡避免抽搐；无数据源（拿不到 RPM）的通道直接静默不合成。
**改动面**：`vendor/audio.js`（Web Audio 封装 ~200 行）+ 布局层开关 + 告警钩子；零后端。

## AC. 屏幕氛围灯 + 全站色温联动 ⭐ 花哨 4 / 实用 3 / 工作量 S-M

**效果**：
- **RGB 边框灯带**：屏幕四周一圈模拟灯珠（canvas 一层，~16px），跑马灯流光颜色 = 各区温度梯度，盘 IOPS 触发单珠爆闪，告警时全圈红色呼吸——桌面摆着像一台发光的机器在呼吸。
- **全站色温漂移**：主题 accent 色随实时负载/温度微偏移（正常不动，高载偏暖、过热全站边缘泛红光晕），只动 CSS 变量不动布局。
- **弹幕 2.0**：拉满档弹幕升级字号/描边样式；Kiosk 模式弹幕变「机房型跑马灯告警墙」（大字居中飘过），既有 NDanmaku（花活 H）的开关与去重逻辑全复用。

**实现要点**：灯带与色温同用一个 rAF 节流器（≥1s 一跳，不逐帧刷）；`prefers-reduced-motion` 时灯带静态化只保留颜色不流光；Kiosk 灯带受 Y 的机器级档位控制。
**改动面**：全局覆盖层组件 + 主题 CSS 变量注入器 + NDanmaku 样式分支；零依赖零后端。

## AD. 时光机延时电影（回放模式 Pro）⭐ 花哨 5 / 实用 3 / 工作量 M

**效果**：一期 C 时光机的电影模式：选中过去 24h / 7d，点「▶ 放映」——底部时间轴自动快进（24h 压成 40s），示波器曲线沿扫描线逐段绘出，机箱热色随回放时刻同步重映射（三期 R 就绪后），关键事件（告警/启停）以字幕条形式在时间点弹出，结尾一帧「本片数据摘要」卡（峰值/均值/事件数）可一键出图（四期 V 接管）。**给这台机器拍了一部纪录片。**

**实现要点**：
- 数据全现成：历史库 1h/1s 桶 + alert_events，零新增采集；回放是纯前端时间游标（一个 shared replay clock store），各图表/机箱组件订阅同一游标——**回放架构 = 现有实时渲染组件换数据源时间戳**，不另写渲染。
- 拖动进度条任意跳转；`prefers-reduced-motion` 时仍可用但转场直切。
- 30 天回放按 1h 桶插值，缺口段显"—"不插假值。

**改动面**：replay clock store + 各视图接游标（渐进）+ 摘要卡；零后端（聚合端点现成）。

## AE. 盘宠牧场（硬盘拟人桌宠）⭐ 花哨 4 / 实用 1 / 工作量 M

**效果**：硬盘页可切「牧场视图」：每块盘一只像素小宠物（CSS box-shadow 画素，零素材零依赖），性格随盘走——心情 = 健康分（四期 J oracle 驱动），体表颜色 = 实时温度梯度，动作频率 = IOPS（忙起来手舞足蹈，闲置打瞌睡）；SMART 有恶化趋势的盘宠物头顶冒汗滴徽章；点开还是那张 SMART 摘要卡。盘挂了，宠物躺平——哀而不伤地汇报坏消息。

**实现要点**：
- 宠物 = 参数化像素图（8×8 网格矩阵，体色/表情/动作三参数），一只 ~40 行配置，纯组件渲染；
- 动画 0.5fps 级超低频切换（setTimeout 换 class，不 rAF 不耗电）；standby 休眠盘宠物盖被子。
- 真实边界与造型边界同三期 R：**造型卖萌允许，数据只经颜色/徽章/动作频率承载**；无 SMART 的盘是「神秘生物」灰色剪影不显假数据。

**改动面**：`UPet.vue` + 牧场视图切换钮 + （可选）Kiosk 加一屏牧场；零后端零依赖。

## AF. 彩蛋体系：Konami 激活 HYPER MODE ⭐ 花哨 5 / 实用 1 / 工作量 S

**效果**：
- 任意页面键入上上下下左右BA：**HYPER MODE 30 秒**——RGB 灯带全速流光（AC）、礼花连发（W 的 canvas-confetti）、声音化切 turbo 音色（AB，若开着）、弹幕飘 `⚠ HYPER DRIVE ENGAGED`、Logo 变色；到时自动回落，全程不碰数据只碰氛围。
- 运行时长里程碑自动小庆祝：连续运行整百天（100/200/300…）当天首次进入，总览页一枚「百日徽章」+ 一轮礼花——稳重的浪漫。
- 彩蛋行为全部登记在效果引擎 Y 名下，关闭档全灭；localStorage 记「已看过的彩蛋」防重复轰炸。

**实现要点**：Konami 序列监听 ~20 行手写（零依赖，不引 konami-code 包——为 20 行引库违反总则）；里程碑计算复用 uptime 现成字段，当天标记落 localStorage。
**改动面**：全局键序监听 + 效果引擎联动；零后端。

## 建议组合

- **演示王炸**：Z 热成像 + AA 流体风道 + AD 延时电影——「这还是个 NAS 面板？」三连
- **氛围三件套**：AC 氛围灯 + AB 声音化 + AF 彩蛋——机器活了
- **社交裂变**：AE 盘宠牧场——发群截图不需要理由
- **地基先行**：Y 总闸最先做，其余全部注册进它的档位；没有总闸的花活是事故，有总闸的花活是产品

## 风险与约定

- **花活永不伤害数据可读性**：任何效果层出现可读性冲突（弹幕挡数字、灯带抢焦点），数据赢，效果让路——组件评审硬性检查项。
- 声音（AB）默认关且须用户手势开启（浏览器策略 + 礼貌）；Kiosk 机器级默认静音，管理员可开。
- WebGL 项（AA）仅拉满档挂载 + 双重兜底（探测失败/上下文丢失 → 粒子层）；帧率自检降档走 Y。
- 老平板验收环境不变：关闭/标准档须在其上 60fps 流畅——拉满档本来就是给能跑的机器准备的。
- 全部零后端新增（AA 数据绑定复用 R2，AD 读现成历史库）；涉及新文案 `t()` 且 key 加引号；每项独立提交可单独砍。
