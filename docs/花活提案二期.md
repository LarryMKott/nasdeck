## I. 磁盘舱位 2.5D 立体墙 + 真实活动灯 ⭐ 花哨 5 / 实用 4 / 工作量 M

**效果**：存储页/硬盘页顶部可切「舱位视图」——一排 2.5D 抽屉式硬盘位（纯 CSS 3D，不引 three.js）：
面板色按实时温度梯度（绿→橙→红），正面活动灯按**真实 IOPS** 闪烁，侧沿厚度按容量，
鼠标平移带视差微倾。点击盘位翻转，背面是 SMART 摘要迷你卡（健康状态 + 关键属性 sparkline）。

**实现要点**：
- 本期唯一新增采集面：`/proc/diskstats` 直读差分出每盘 IOPS 与读写 MB/s（零 fork，进 fast_1s 实时快照 + raw 落库）——示波器顺带多出「每盘」通道。
- 前端新组件 `UDiskBays.vue`：`perspective + preserve-3d`，rAF 节流；RAID 卡虚拟盘等拿不到 diskstats 的盘 LED 恒灭、数值显"—"。
- 盘位按系统盘序排列；「物理槽位映射」（Backlog 项）本期不做，留接口。

**改动面**：新采集器 + realtime 快照字段（同步 Pydantic）+ 新组件挂 Storage/Disks 两视图。

## J. 硬盘健康预言 ⭐ 花哨 4 / 实用 5 / 工作量 M

**效果**：每块盘一个 0–100 健康分徽章 + 五维雷达图（重映射增速 / 待定扇区 / 介质错误 / 温度余量 / 磨损度），
外加「按当前增速，预计 N 天后触及阈值」倒计时条——把 smart_points 里存了 90 天的历史真正变成预言。

**实现要点**：
- 后端新服务 `smart_oracle`：复用 `capacity.py` 最小二乘先例，对 8 项 TRACKED_METRICS 做 1h 桶斜率。
- ETA 只在拿得到阈值时给出：ATA 解析 smartctl 输出的 THRESH 列，NVMe 直接用 percent_used 剩余寿命；拿不到显式"—"。
- 评分加权：变化速率为主、绝对值为辅；无历史的新盘只按当前值给分。
- 挂 `/storage/disks` 响应 `oracle` 字段（**response_model 静默过滤，必须同步改 Pydantic**）；评分进 Kiosk 硬盘屏与周报。

**改动面**：预测服务 + API 字段 + 手写 SVG 雷达组件（主题色联动）。

## K. 进程风暴榜 ⭐ 花哨 3 / 实用 5 / 工作量 S-M

**效果**：总览页新磁贴：CPU Top 8 / 内存 Top 8 双榜实时条形，排名变化 FLIP 动画换位，榜首橙色高亮；
示波器页角落加「当前榜首进程」读数。

**实现要点**：
- psutil `process_iter`（/proc 直读，零 fork）放 5s 档，两次采样均值去抖，top N 进 realtime 快照 `top_procs`。
- 口径沿用端口页：仅进程名 + pid + 占用，不暴露启动路径/参数；终止进程仍走端口页白名单逻辑。

**改动面**：采集 + 快照字段 + DashView 磁贴。

## L. 网络星图 ⭐ 花哨 5 / 实用 2 / 工作量 M

**效果**：canvas 星空：NAS 是中心恒星，监听端口是星环亮斑（亮度 = 连接数），ESTABLISHED 连接是绕轨
粒子（内网/外网不同色）；下方每网口一条「双向粒子河」，粒子密度与流速 ∝ 真实 rx/tx kbps。

**实现要点**：
- 数据几乎全现成：每网口 kbps 已在实时流；ports 服务补输出 ESTABLISHED 连接（同一次 psutil 调用顺带取，按内网/外网归类，不引 GeoIP、不出网）。
- 严格真实口径：粒子代表连接状态与网口吞吐，**不伪造每连接带宽**（/proc/net 不给这个数）。
- rAF + 页面隐藏即停（示波器同款护栏）。

**改动面**：ports 响应增补 + 新 canvas 组件（挂硬件检测网络区或独立面板）。

## M. Docker 舰队 + 容器 IO ⭐ 花哨 3 / 实用 5 / 工作量 M-L

**效果**：Docker 页从表格升级为「舰牌墙」：每容器一张卡——状态环 + CPU/内存/**磁盘 IO** 三实时条 +
24h 迷你趋势；OOM/意外退出徽章联动事件时间线；管理员可直接启/停/重启。

**实现要点**：
- 后端：cgroup v2 `io.stat` 直读补每容器读写 B/s（零 fork；v1 回退不支持则该列显式"—"）。
- 每容器网络口径不可靠（共享 netns）——明确不做，不造假数据。
- 新表 `container_points`（1m 桶，保留 7 天）存 CPU/内存/IO 趋势。
- 容器写操作走现有管理员强校验。

**改动面**：采集 + 新表 + DockerView 重排。

## N. 一键体检 NAS Score ⭐ 花哨 4 / 实用 4 / 工作量 M

**效果**：总览页「一键体检」按钮：全屏序列动画逐项检查打勾（硬盘预言 / 容量预测 / 阵列状态 / 温度余量 /
30 天告警 / 端口暴露面），最后总分环 SVG 描边动画揭晓，一键生成分享 PNG（复用脑洞 B 的 canvas 模块）。

**实现要点**：

- 只读接口，不出网；动画可跳过，`prefers-reduced-motion` 直接出结果页。

**改动面**：聚合端点 + 前端 sequence 组件（依赖 J 先做才有「硬盘预言」维度）。

## O. 开机自检动画（POST 风）⭐ 花哨 5 / 实用 1 / 工作量 S

**效果**：会话首次进入时播放 2–3 秒 BIOS POST 序列：主板/CPU/内存/盘数等**真实硬件行**逐行打出，
内存容量滚动计数，最后一行 `OK` 后淡入仪表盘。点击跳过；localStorage 记住「不再播放」。

**实现要点**：
- 纯前端零后端：数据源 detect API 已有；首帧并行拉取，数据未到就先播过场不播数字（不放假数据）。
- `prefers-reduced-motion` 自动禁用；terminal/cyber 主题下尤其带感。

**改动面**：布局层一个全屏覆盖组件 + 一个开关。

## P. 大屏「星舰 HUD」升级 ⭐ 花哨 5 / 实用 2 / 工作量 S-M

**效果**：Kiosk 大屏加氛围层：底部一条示波器同款荧光波形带（复用其环形缓冲渲染内核）；
屏幕轮播加径向擦除转场；firing 告警时全屏边缘红光呼吸；cyber/terminal 主题自动适配。

**实现要点**：
- 把 OscilloscopeView 的渲染内核抽成公共模块，Kiosk 复用。
- Kiosk 目前纯 5s 轮询：顺带把 alert 事件帧并入轮询响应驱动红光。纯观感，不碰数据口径。

**改动面**：渲染内核抽取 + KioskView。

## Q. 硬盘跑分中心（只读基准）⚠ 花哨 4 / 实用 3 / 工作量 M-L / 唯一重 IO 项

**效果**：手动触发单盘顺序读基准 → 实时速度曲线 → 成绩入库形成跑分榜（同盘历史对比、盘与盘雷达对比）。

**实现要点与护栏**：
- **只读不写**：Python 直接 pread 设备（绕页缓存），不碰任何数据安全。
- 仅管理员手动触发；全局锁同一时间只跑一个；standby 盘默认跳过（不唤醒）；
  块间微休眠限速，默认把 IO 占用压到 30% 上下（可调）。
- 纯 Python 实现零新依赖（不依赖 fio/dd）；进度走事件流，成绩落库。
- 风险直说：基准期间业务盘延迟上升是物理规律，护栏只能减不能免——因此不做定时任务、不做排队。

**改动面**：新任务服务 + API + DisksView 面板。

- 契约先行：所有新增响应字段同步 Pydantic model 与接口文档；新文案走 `t()` 且 key 加引号（i18n 约定）。
- 动画护栏：rAF 组件一律页面隐藏即停；`prefers-reduced-motion` 全量适配；新视图遵守真实数据约定（无源显式"—"）。
