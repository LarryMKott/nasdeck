# nasdeck 正式版发布计划(v1.0.0 提案)

> 状态:**规划**(2026-10-09)。本文是正式版发布的唯一执行清单;发布动作按 §5 顺序走。
> 基线:dev-0.2.16(2026-10-09,提交 b8ae40c),pytest **259 项全绿**。

## 1. 版本号:v1.0.0

- 理由:Vue3 + FastAPI 重构后的新一代首版;旧 Flask 线(v2.3.3 及更早)已归档 `backup/`,
  版本线不延续。`1.0.0` 明确表达"新一代正式可用"。
- 版本通道语义(已实现,`app/core/config.py`):`dev-` 前缀 → 日志缺省 DEBUG;
  无前缀(正式版)→ 缺省 INFO。**切版本号即切日志通道,无需代码改动。**
- 单源:`backend/pyproject.toml` → 打包脚本注入 manifest `@VERSION@` → 运行时
  `config.app_version` 读随包 pyproject。前端 about 页 live 模式读后端接口,无需同步。

## 2. 范围

**v1.0.0 包含**(已全部落库,dev-0.2.x 累计):

- 监控:17 视图(总览/存储卷/硬盘/硬件检测/系统资源/温度/示波器/趋势/Docker/端口/风扇/
  事件时间线/自动化/操作手册/关于/设置 + 大屏 Kiosk)
- 花活全量:时光机、命令面板、状态分享卡、NAS Score 体检、事件弹幕、大屏轮播(健康分)、
  多通道示波器、主题皮肤包、网络星图、跑分中心、2.5D 立体机箱、开机自检动画、周报预言
- i18n 两期(中文为主,英文覆盖框架外壳与主要视图;风扇页/渠道编辑器未迁移,**已知限制**)
- 打包层:CGI 反代单模型 + 安装向导自定义端口 + 配置向导 + ui 镜像 start 自愈(85ed6f7)

**v1.0.0 不包含**(有意排除):

- 访问模型切换(CGI/统一网关)——网关存活判定(10-11)与实施(约 2.5-3 天)见
  [访问模型切换方案](访问模型切换方案.md),列 **v1.1** 候选。
- Alembic 正式迁移(现 init_db 结构自愈够用,SQLite 单文件场景风险低)
- UPS / per-NIC 曲线等 Backlog(见 docs/开发计划.md)

## 4. 已知限制(随 v1.0.0 发布,README/手册如实标注)

- WS 实时推送经 CGI 反代不可用 → 前端 2s 轮询(设计内;网关化后消除,见 v1.1)
- i18n:风扇页与渠道/规则编辑器暂中文
- `platform=x86`:ARM 机型缺阵列卡功能(其余降级)
- 健康报告 HTML 落应用 target 目录,升级会清(数据本体在 @appdata 不受影响)
- 跑分中心自带读 IO 负载(占空比限速默认低档,页面有明示)

## 5. 发布动作(顺序执行)

1. 门槛 A 本地全过 → 构建 `nasdeck-fnpack-1.0.0.fpk`
2. 门槛 B 真机全过(试验包 gatewayprobe 此时已按结论处置:卸载或转观察)
3. 版本同步门 D 三处落盘 → 提交 `chore(release): 版本 1.0.0——…`
4. `git tag v1.0.0 && git -c http.proxy=http://127.0.0.1:7890 push origin dev v1.0.0`
   (push tag 触发 release.yml:compileall + pytest → build_fpk → GitHub Release,
   产物 `nasdeck-fnpack-1.0.0.fpk`,说明取 manifest changelog)
5. Release 页面核对产物与说明;应用中心手动安装分发(官方注明 .fpk 本地安装仅限测试,
   正式分发走应用中心 / GitHub Release)

## 6. 回滚

- Release 层:GitHub 删 v1.0.0 Release + tag,重新出包即可(应用数据在 @appdata,与包无关)
- 用户侧:应用中心降级重装旧包;数据库结构由 init_db 启动自愈兜底

| 时点 | 事项 |
