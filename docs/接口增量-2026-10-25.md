# 接口增量说明（2026-10-25 健壮性批次）

> 主契约文档（`docs/前后端数据接口约定.md`、wiki 06）本轮未改动——本文记录 2026-10-25
> 评审修复与健壮性模块引入的 **新增端点、响应字段与校验行为变化**，供主契约下次合并时收录。
> 全部为增量（只加不改名不删），旧消费方不受影响。

## 一、新增端点

### GET /api/v1/system/diagnostics（自检聚合）

```json
{
  "generated_at": "2026-10-25T12:00:00+00:00",
  "groups": [
    { "name": "数据管线", "items": [ { "key": "ingest_stall", "status": "ok|warn|fail|skip", "detail": "…", "hint": "修复建议（可空）" } ] }
  ]
}
```

五组：数据管线 / 风扇 / 鉴权链 / 采集工具 / 通知。`skip` = 当前形态不适用（不制造假红）。

### GET /api/v1/control/fans/events（调速事件环形缓冲）

`[{ts: <epoch 秒>, zone_id, name, error, failsafe}]`，新→旧，上限 20 条。
`failsafe` 取值：`hold` / `full_speed` / `critical` / `restore_failed` / `tick_error`（无则 null）。

### POST /api/v1/control/fans/{id}/restore-auto（手动重试交还内核）

`{id, restored: bool}`——交还失败后的补救入口。

## 二、响应字段增量

| 端点/模型 | 增量 |
|---|---|
| GET /monitor/history | `gaps: [[start, end], ...]`（相邻点间隔 > 2×粒度标称步长的断口，ISO UTC 串，上限 50 段；跨粒度接缝不误报） |
| GET /alert/channels | 每项 + `health: {send_failures, last_error, last_ok_ts, last_attempt_ts, overflow_dropped} \| null` |
| POST /alert/channels/{id}/test | + `reason`（错误码）/ `detail`（中文说明）；`success` 语义不变 |
| DELETE /alert/channels/{id} | 被规则引用时响应带 `referenced_by: [rule_id…]` |
| VolumeItem | `total_bytes/used_bytes/free_bytes/percent` 可空；网络文件系统挂载 `stale: true`（不探测容量） |
| FanZoneIn / FanZoneUpdate / FanZoneItem | + `chip_path`（/sys/class/hwmon/hwmonN 绑定，同名芯片消歧；驱动层校验必须落在 hwmon 根内） |
| WS fans 事件条目 | + `critical: true`（临界温度 ≥85℃ 无条件全速时）；curve missing 条目改走 failsafe（hold→full_speed） |

## 三、校验与行为变化

- `PUT /settings/{key}`：键限 `^[a-z0-9_]{1,64}$`，值序列化后 ≤8KB（1002）
- 告警规则 `threshold` 禁 NaN/Inf（422）；`channel_ids` 须全部存在（1002）
- 控区 `mode=curve` 必须带有效 `curve_id`（创建 422 / 更新 1002）；chip 在位但通道缺失或只读 → 1002
- `DELETE /system/processes/{pid}`：pid<1 → 1002；SIGKILL 后仍未退出 → `{killed: false, reason}`（不再谎报成功）
- 未处理异常信封固定 `internal error`（原异常文本只进日志）
- 渠道 send（内部契约）：`bool` → `str | None`，错误码 `ssrf_rejected / timeout / network / auth_failed / bad_response / invalid_config`
- 升级/重装：`ui/proxy_token` 镜像随 port 一并恢复（升级后不再面板全量 403）

## 四、运维相关

- `NASDECK_DB_ALLOW_REBUILD=false`：检测到旧结构拒绝整库重建并中止启动；默认重建前自动备份 `nasdeck.db.bak.<ts>` 并落 `system_settings.db_rebuilt_at` 标记（自检页展示）
- 启动日志新增 `proxy_token=set/unset`；trim_auth+空 token 有显式 warning
- CI：全部 actions pin commit SHA；ruff 钉 0.4.4 与 pre-commit 同版本；前端 CI 构建改 `--mode fpk` 且打包校验 dist 资源前缀
