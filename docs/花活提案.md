# nasdeck 花活提案（design-only，待拍板）

> 原则：只花哨不折腾——全部特性零新增采集 fork（复用 WS 实时流 / 历史库 / SMART 缓存），
> 不碰权限模型，不做破坏性改动。每项标注：花哨度 / 实用度 / 工作量 / 改动面。
> 你勾选哪几项，我就按对应小节的设计实现。

---

## A. 大屏轮播模式（TV 监控墙）⭐ 花哨 5 / 实用 4 / 工作量 S

**效果**：一个 `/kiosk` 全屏页——时钟 + 轮播卡片流（总览仪表 → 硬盘健康 → 温度墙 → 最近事件），
每隔 N 秒淡入淡出切换一屏，字体放大、纯黑底、动画数字滚动。把淘汰的平板/电视往 NAS 旁一挂，
就是一面"机房监控墙"。

**实现要点**：纯前端新视图（隐藏路由，不占页签）；复用各页取数 service + WS 实时流；
轮播间隔/可见卡片组由 URL 参数或 localStorage 配置；数字滚动用 CSS counter 动画。
Esc 退出 / 点击暂停。

**改动面**：新增 KioskView + 布局白名单（kiosk 不套 UnraidLayout 顶栏）。

---

## B. 状态分享卡片（一键生成 PNG）⭐ 花哨 5 / 实用 5 / 工作量 S

**效果**：总览页角落一个「生成状态卡」按钮——把当前 CPU/内存/温度/阵列/运行时长渲染成一张
精美分享图（品牌橙渐变 + 大数字 + 盘健康条），一键下载 PNG，发群晒 NAS 利器。

**实现要点**：Canvas 2D 手绘（无新依赖）：双线性渐变底、圆角卡、数据从 realtime 缓存取；
模板三选一（深色橙 / 极简白 / 终端绿）；文件名 `nasdeck-status-<date>.png`。

**改动面**：DashView 加按钮 + 新 canvas 渲染模块。后端零改动。

---

## C. 历史时光机（回放模式）花哨 5 / 实用 5 / 工作量 M

**效果**：总览页顶部出现「时光机」开关——开启后顶部浮出时间轴滑杆（近 2h 秒级 / 30 天按粒度），
拖动滑杆整个仪表盘"回到过去"：CPU/温度/网络显示所选时刻的值，卡片右上角亮"回放中"标签；
配合播放键可自动快进回放「昨晚 20:00-22:00」完整过程。

**实现要点**：历史 API 已有（/monitor/history 三级粒度）；前端按滑杆位置拉取对应时间点数据，
喂给现有卡片组件（组件已接受 data prop，只需加时间戳覆盖层）；播放 = 定时步进。
注意与 WS 实时流的互斥（回放模式暂停实时订阅渲染，退出恢复）。

**改动面**：DashView 时间轴条 + 数据源切换逻辑；后端零改动（history API 够用）。

## D. 多通道示波器页（CPU/网速/IO 波形）花哨 4 / 实用 4 / 工作量 M

**效果**：新页签「示波器」——绿色荧光网格上多条滚动漫迹：CPU%、网速上下行、磁盘读写、
各盘温度（可选通道），带暂停/缩放/游标读数，活像示波器。观察"抖动""突刺"比折线图爽得多。

**实现要点**：Canvas requestAnimationFrame 滚动渲染（环形缓冲，WS realtime 每秒推入）；
通道开关 + 垂直游标吸附数据点显示精确值；性能护栏：分辨率自适应、标签页隐藏时暂停 rAF
（与 keep-alive 停轮询约定一致）。

**改动面**：新 OscilloscopeView + navGroups 加页签；纯前端。

## E. 命令面板（Ctrl+K）花哨 3 / 实用 5 / 工作量 S

**效果**：任意页面按 Ctrl+K（或 `/`）呼出居中悬浮面板：模糊搜索页签/硬盘/容器/Docker 服务，
回车直达；输入 `temp 60` 直接预填一条告警规则。键盘党的效率外挂，也是"高级感"来源。

**实现要点**：全局 keydown 捕获（布局层）；候选 = 路由 + 动态实体（盘位/容器名从各页缓存取）；
fuzzy 匹配手写 30 行（无新依赖）；选中执行 router.push 或跳转预填。

**改动面**：UnraidLayout 挂全局组件；各页暴露少量实体清单（可选，缺省只搜页签）。

---

## F. 机箱热力图（温度×位置可视化）花哨 5 / 实用 4 / 工作量 M-L

**效果**：温度页新增「机箱视图」——一块 2D 机箱示意：主板/CPU/硬盘笼/电源位置摆块，
按实时温度着色（绿→橙→红），风扇位置画动态气流线（速度 = 实际转速），盘位可点击看详情。
悬停任意区块浮出该传感器实时读数。

**实现要点**：布局用网格编辑器让用户拖放传感器位置（localStorage 持久化，默认给通用布局）；
温度源 = temperature service 既有清单；气流线 = CSS 动画按 fan_outputs RPM 调速。

**改动面**：TempsView 加视图切换 + 布局编辑器；纯前端（数据全有）。工作量主要在编辑器交互。

## G. 主题皮肤包（赛博朋克 / 终端绿 / CRT）花哨 4 / 实用 2 / 工作量 S

**效果**：主题按钮循环扩展为「黑 / 白 / 赛博朋克（霓虹紫青）/ 终端绿（磷光 CRT，带扫描线
与轻微辉光）」四套；切换即时生效并持久化。纯 CSS 变量换肤，全局瞬间换装。

**实现要点**：data-theme 扩枚举 + 变量覆盖层；CRT 扫描线 = repeating-linear-gradient 叠层
（prefers-reduced-motion 时关闭闪烁动画）；现有组件全部走 CSS 变量，零适配成本。

**改动面**：unraid.scss 变量组 + appStore.theme 扩枚举。

---

## H. 事件弹幕花哨 5 / 实用 1 / 工作量 S

**效果**：开关打开后，告警/巡检/容器事件以弹幕形式从顶栏右侧飘过（"容器 plex 意外退出"），
半透明小字不遮挡操作，纯氛围组。可在设置关闭。

**实现要点**：WS alert/事件消息 → 弹幕队列（CSS animation 平移，同屏限 3 条）；
数据源就是现有 latest_alert_events 推送。

**改动面**：布局层弹幕层组件 + 开关（localStorage）。

## 建议组合

- **最值组合**（花哨与实用双高）：B 分享卡片 + C 时光机 + E 命令面板
- **最秀组合**（纯氛围）：A 大屏轮播 + G 皮肤包 + H 弹幕
- **单点体验升级**：D 示波器 或 F 热力图（二选一即可，都是重交互）

## 风险与约定

- 全部特性不加新依赖、不加采集 fork；性能敏感的动画（D/F/H）均带 rAF 节流与隐藏暂停。
- 大屏/弹幕/皮肤只影响观感，不改变任何数据口径与权限行为。
- 每项独立提交，可单独砍掉。
