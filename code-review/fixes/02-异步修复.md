## 关键实现选择
- **downsampler**：封口判据放插入循环而非 select 加上界——一处改动对两次聚合调用统一生效，且不动查询与删除路径；`current_key` 在循环前计算一次（单轮运行秒级，桶边界不会中途翻转，逐桶重算无收益）。`_iso_minutes_ago(0)` 恒产出合法 ISO 串，`current_key` 不会为 None（已在注释注明）。
- **gpu**：选「调用链 async 化」而非 `asyncio.to_thread(reader.ensure)`——后者会把 `_proc/_name/_next_try` 等实例状态变更挪进工作线程，引入与事件循环的跨线程读写面；async 化改动封闭在 gpu.py 内，且每 5s 拍不再有线程池派发开销。毫秒级 Popen 惰性 fork 按评审口径保留在循环上（评审只要求 lspci 最坏 10s 等待出循环）。
- **temperature**：模块级 `asyncio.Lock` 在无竞争路径不绑定事件循环（Python 3.13.15 实测验证），现有测试多次 `asyncio.run` 的用法不受影响；锁竞争只发生在生产单事件循环内，属正确场景。
