## 探索稿：UNRAID 风格（nasdeck-unraid.html）

> 与 fnOS 风格稿平行的设计探索：模拟 UNRAID webGUI 的设计语言重新设计，
> **不参考现有 nasdeck 视觉与图标资产**——令牌、组件、图标全部为本稿新做。
> 单文件、零依赖、纯前端 mock，浏览器直开（file:// 即可）。

### 布局（与 fnOS 稿的最大差异）

- **Web 端**：放弃左侧栏，改为 UNRAID 式**顶部横向页签导航**（品牌 + 13 个页签 + 搜索/通知/主题/用户一行），
  内容为 **max-width 1240 居中单列**，卡片全宽堆叠；页签可横向滚动。
- **移动端**：<900px 页签收进**汉堡下拉面板**（带遮罩），栅格纵排、表格转卡片。
- 新增 **Dashboard 总览首页**（UNRAID 招牌）：CPU（含每核小柱与负载）/ 内存 / 网络吞吐 / 磁盘 IO /
  阵列 / GPU / 整机功耗 / 系统（运行时长·负载·进程数）八磁贴 + **风扇转速**（三扇 RPM 大数 +
  占空比橙条 + PWM/DC 芯片 + 旋转扇叶，接管状态徽标）+ Docker 速览 + 硬盘温度墙 +
  缓存与备份（NVMe 缓存 / 云盘同步）+ 活动告警，共 13 个视图。
- **存储卷页按 UNRAID Main 页重做**：Array Operation 卡（阵列运行状态 + 启动/停止/校验 Parity 按钮）、
  阵列设备表（设备/盘位/文件系统/温度色阶/读写/容量条/状态）、卷与云盘拓扑。

### 视觉与图标

- 黑色主题为默认（UNRAID"black"主题取向），可切白主题（localStorage 持久化）；
  品牌橙 `#F15A2C` 为唯一强调色，绿/琥珀/红仅作状态语义色。
- 盒状组件（小圆角 6-8px）、细边框、大写字距表头、温度/用量按阈值着色——UNRAID 式数据密度。
- **图标全部重新生成**：本稿新绘的几何风格内联 SVG sprite（约 40 枚），未复用 icons.ts 的
  lucide 路径，也未引用 `ui/images` 的彩色插画；品牌标换为橙色圆角方块 + 白色"deck 堆叠"符号。
- **导航**：顶部横向页签（品牌 + 13 页签 + 搜索/通知/主题/用户一行），默认为文字页签、激活态橙色
  文字 + 底部橙色下划线；左上角菜单按钮点击**仅在两种页签样式间切换**——「纯图标」（38px 启动器式
  小方块，激活橙底橙标、计数徽标转角标）↔「完整样式」，localStorage 持久化；纯图标态按功能
  **分为 5 组**（总览｜存储｜监控｜服务｜系统），组间分隔线、整条菜单均匀分布；窄屏页签横向滑动。
- 图表沿用自研 SVG 引擎但按 UNRAID 配色重调（十字线 tooltip、dataZoom、风扇曲线拖拽编辑均保留）。
- 总览含 **GPU 详细监控卡**（Intel HD P530 核显：使用率/共享显存/编码解码引擎占用/频率/温度/功耗/驱动 +
  GPU 与显存双序列 60s 走势图）。

### 打开方式

浏览器直接打开 `nasdeck-unraid.html`，或访问 `http://127.0.0.1:PORT/prototype/nasdeck-unraid.html`。
自检截图在 `prototype/_shots/`（`u-*.png`，已 ignore）。

### 相对线框的兑现与增强

- **真实主题三态**：浅色 / 深色 / 跟随系统（`[data-theme]` + prefers-color-scheme），localStorage 持久化，auto 档按钮带品牌描边。
- **图表**：线框 `chart-ph` 虚线占位全部兑现为手写 SVG——折线 + 渐变面积 + 十字线 tooltip（时间 + 多系列数值、越界自动翻转）、历史趋势 dataZoom 滑块（拖窗口平移 / 拖手柄缩放）、StatCard sparkline、风扇曲线拖拽编辑（圆点可拖、添加点 / 重置、拖拽实时读数）。
- **组件高保真**：渐变状态徽章、玻璃顶栏/侧栏（backdrop blur）、卡片品牌短线标题与悬浮抬升、温度墙三档着色（过热档脉冲）、自检进度条纹动画、盘位/DIMM 格子健康色顶边、拓扑树引导线、日志流分级配色。
- **交互增强**：自检 ▾ / 报告导出 ▾ 真下拉菜单、确认气泡改 fixed 定位（不再被表格滚动裁剪）、弹窗内气泡保留宿主弹窗、端口页搜索 × 可达性实时筛选、接管开关联动页头徽章、立即刷新旋转 + 时间戳更新、`/` 键聚焦页面搜索。
- **动效**：换页 fadeUp、弹窗 modalIn、扇叶随占空比变速旋转（fan icon）；`prefers-reduced-motion` 下全部动画降级。

# 阶段1 低保真线框（存档）

> 依据 [`docs/NasDeck前端界面重设计方案.md`](../docs/NasDeck前端界面重设计方案.md)（2026-09-29 定稿）产出。
> 单文件、零依赖、纯前端 mock，无任何后端调用。**先评审结构与流程，通过后再做高保真。**

## 打开方式

浏览器直接打开 `nasdeck-wireframe.html`（file:// 即可，无需服务）。

- **桌面端**：≥768px 宽度即桌面布局（侧栏 208px，可折叠为 60px 图标栏）。
- **手机端**：窗口缩窄到 <768px 自动切换移动布局（侧栏转抽屉、栅格纵排、硬盘页表格转卡片）。
- 右下角有当前视口指示（评审辅助，非界面元素）。

## 页面清单（与现网 12 页 IA 一一对应）

| hash | 页面 | 线框要点 |
|---|---|---|
| `#/detect` | 硬件配置检测 | 8 个可折叠分区（系统/主板/CPU/内存/GPU·网络/RAID/硬盘概览）；内存 DIMM 格子 → 详情弹窗；实时频率/温度行内徽章；WoL/盘定位/CC/热备/CopyBack 操作占位 |
| `#/system` | 系统资源 | 5 枚 StatCard 速览 + RAPL 功耗卡；CPU/内存/网络/磁盘IO 折线占位；网卡 eth0/eth1 页签切换 |
| `#/temps` | 温度监控 | 4 枚 StatCard + 温度墙 tile 网格（灰阶三档 + 分档图例） |
| `#/sys-hist` | 历史趋势 | 24h/7d/30d 单选组；六维度 chips；大图占位（十字线 tooltip + dataZoom 滑块）；报告导出 MD/HTML/CSV |
| `#/disks` | 硬盘 SMART | 桌面表格（健康 StatusTag/转速/容量/自检·改名·定位）+ 移动端卡片流；进行中自检进度条 |
| `#/storage` | 存储卷 | 阵列/卷状态卡（StatusTag + KvList）+ 容量进度条 + 卷映射拓扑树 + 云盘标记 |
| `#/fan` | 风扇控制 | 接管总开关卡；风扇卡 ×3（RPM 大数/占空比滑杆/PWM·DC 开关/重命名·隐藏）；曲线编辑器占位（拖拽点）；两套温控规则表单 |
| `#/docker` | Docker | 容器表格（状态/内存/CPU/网速/端口映射/时长） |
| `#/ports` | 端口占用 | 搜索 + 可达性筛选；表格（应用/端口/进程/可达三级 StatusTag/释放 → 确认气泡） |
| `#/automation` | 控制与自动化 | 三区页签（活动告警/规则与通知/报告导出）；日志与错误历史弹窗（日志流 + 清空二次确认） |
| `#/manual` | 操作手册 | 正文 prose 占位 + 「目录」右侧抽屉 |
| `#/about` | 关于 | 品牌区（插画 PNG 保留地）+ 检查更新卡 + 构建信息 KvList |

## 页面跳转逻辑

```
顶栏搜索（桌面）──回车──► 跳转命中页
侧栏 NAV（4 分组 12 项）──点击──► hash 换页（#/xxx），移动端抽屉自动收起
跨页关系（与现网一致，由跳转总线实现，原型中从简）：
  detect 硬盘概览 ──► disks    detect RAID ──► storage
  system ──► sys-hist / temps  automation 告警 ──► temps/disks
默认首屏：#/detect；未知 hash 兜底回首屏
```

## 组件清单（对应高保真阶段的组件体系）

- **壳层**：TopBar（品牌/页面搜索/新鲜度/主题三态/移动汉堡）、SideNav（分组/active 左指示条/折叠 rail/移动抽屉）、PageHeader（标题·副题·健康徽章·stats·最后更新·自动刷新·立即刷新）
- **业务原子**：StatCard、StatusTag（圆点+文字）、KvList、SectionCard（含操作区）、EmptyState（未演示）、盘位/DIMM slot 格子
- **图表占位**：chart-ph 虚线占位（→ 高保真换 ECharts：折线+十字线 tooltip+dataZoom、风扇曲线拖拽编辑）
- **控件**：按钮（主/次/小）、开关 switch、单选组 radios、页签 tabs、筛选 chips、下拉、滑杆、进度条、确认气泡（→NPopconfirm）
- **浮层**：Modal（内存详情/日志流）、Drawer（手册 TOC）、新鲜度告警横条

## 交互说明（均可点）

hash 换页 · 侧栏折叠（localStorage 持久化）· 移动抽屉（汉堡/遮罩/换页收起）· 页面搜索过滤+回车跳转 · 主题三态循环（线框仅切文案）· 新鲜度告警演示（点顶栏「实时」）· 页签/单选/chips 切换 · 分区折叠 · 弹窗/抽屉开关（遮罩/✕/Esc）· 确认气泡（确认/取消）· 开关/滑杆演示

## 已知简化（低保真范围约定）

黑白灰线框、无配色与图标细节；数据全部写死；「立即刷新/自检 ▾」等按钮仅样式占位；Docker/Ports 表格移动端为横向滚动（卡片化列入高保真迭代评估）。
